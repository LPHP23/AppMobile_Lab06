## Chức năng

- Chọn ảnh tài liệu hoặc trang sách từ thư viện.
- Xóa bóng theo pipeline trong hint: chuyển HSV, xử lý kênh V bằng max filter/dilate, blur nền, absdiff, invert và normalize.
- Chuyển ảnh sang grayscale.
- Tạo bản scan trắng đen bằng threshold cục bộ.
- Reset ảnh gốc.
- Lưu ảnh kết quả vào `Pictures/Lab6Scanner`.

## UI

- Giao diện đơn giản, dễ dùng.
- Các tính năng đặt trên các nút bong bóng có emoji.
- Palette chính: `#0050D1`, `#B3D1FF`, `#666BFF`.
